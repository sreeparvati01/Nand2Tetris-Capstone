## 1. Introduction

This capstone project demonstrates the Hack computer at hardware and software levels. It includes the CPU, Memory and Computer HDL components, a Python two-pass assembler, and a Hack assembly program that draws a filled rectangle while a keyboard key is pressed. The project is personalized using K = 36, the last two digits of university roll number 2501730236.

The required rectangle starts at screen row 36, is 20 rows tall, and is 16 × ((36 mod 4) + 1) = **16 pixels wide**. Since one Hack screen word represents 16 horizontal pixels, the program writes one word per row. The first screen word is at SCREEN + 32 × 36 = **17536**.

## 2. Part A: Build the Computer

### 2.1 CPU.hdl

The CPU executes Hack A-instructions and C-instructions. It uses the A-register, D-register and ALU to process instructions, access data memory and determine jump behavior. The program counter supplies the address of the next instruction. The submitted HDL implementation is in `CPU.hdl`.

### 2.2 Memory.hdl

The Memory chip provides the Hack data-memory interface. It selects the appropriate memory-mapped component according to the address: RAM for data, Screen for display memory, and Keyboard for keyboard input. The implementation is in `Memory.hdl`.

### 2.3 Computer.hdl

The top-level Computer connects the CPU, instruction ROM and Memory chip. The CPU fetches instructions using the program counter and communicates with data memory through the memory interface. The implementation is in `Computer.hdl`.

## 3. Part B: Python Assembler

### 3.1 Two-pass design

The assembler in `assembler.py` converts Hack assembly (`.asm`) into 16-bit machine instructions (`.hack`). In the first pass, it removes comments and blank lines and records label declarations with their ROM instruction addresses. In the second pass, it translates A-instructions and C-instructions. New variables are assigned RAM addresses starting at 16.

### 4.2 Program behavior

`Box.asm` continuously checks the memory-mapped keyboard. It sets the drawing value to zero by default, which clears the box when no key is pressed. When a key is detected, it sets the drawing value to -1, making all 16 pixels in the screen word black. A loop writes that value to one word in each of 20 rows. The address advances by 32 words after each row because a Hack screen row contains 32 words. The program then repeats the keyboard check.
